# 桌面宠物 · 桌面交互层 产品规格

状态：已通过交互原型确认（浏览器模拟版），作为代码实现的依据。

## 状态机

三种状态，显示文字：

| 状态 | 文字 | 触发 |
| --- | --- | --- |
| 等待 | 等待 | 默认状态 |
| 打开 | 打开 | 悬浮宠物满 500ms（悬浮意图延迟）或点击后面板处于打开状态（持续） |
| 移动 | 移动 | 按住宠物 ≥ 350ms（长按） |

优先级：移动 > 打开(悬浮或面板打开其一即可) > 等待。

## 交互细节

1. **悬浮**：鼠标进入宠物窗口并停留满 500ms（悬浮意图延迟，避免鼠标只是划过就闪一下）且未处于移动状态 → 文字"打开"；未满 500ms 就移出则什么都不触发；已进入"打开"后移出 → 文字回落（若面板仍打开则保持"打开"，否则"等待"）。
2. **单击（按下并在 350ms 内松开，未移动）**：在三个状态间循环推进 `等待 → 打开 → 存储区 → 等待`。
   - 从"等待"点击：显示 3 个无边框浮动面板——图片 / 文本 / 网页，位置相对宠物窗口偏移 `(-160,-35) / (0,-170) / (160,-35)`（首次打开时定位，之后跟随打开动作重新贴合宠物当前位置）。
   - 从"打开"再次点击：收起 3 个面板，展开**存储区**（preview 窗口的剪贴板历史列表，带文本/图片筛选、置顶、删除）。默认选中历史中最新的一条，避免内容区一进来是空白；历史为空时只展示空列表。
   - 从"存储区"再次点击：收起存储区，回到"等待"。存储区自身的关闭按钮和 Esc 也能收起。
   - 三个面板和存储区窗口都只是隐藏、不销毁，已展示内容会保留到下次打开。
3. **长按（按住 ≥ 350ms）**：进入"移动"，宠物窗口实时跟随光标；松开退出移动，回到"打开"或"等待"。纯计时判定，不设位移阈值。
4. **粘贴（Ctrl+V）**：仅当面板处于打开状态时生效，**不要求焦点在宠物窗口上**——通过全局快捷键实现，面板打开时动态注册，面板关闭时立即注销，避免影响其它软件的正常粘贴。触发后读取系统剪贴板：
   - 剪贴板为图片 → 展示在"图片"面板
   - 剪贴板文本匹配 `^https?://` → 展示在"网页"面板，仅显示链接文字，不做跳转/预览/其它网页相关操作
   - 其它文本 → 展示在"文本"面板
   - 每次粘贴只更新匹配类型的那一个面板，其余两个保持原样

## 非目标（本轮不做）

- 真实贴图/骨骼动画渲染（占位阶段只显示状态文字）
- 网页面板的跳转、预览、爬取等任何网页操作
- 后端服务层对接（backendClient 先本地 mock）
- 多宠物/多剪贴板历史记录

## 商业化基础项

- 系统托盘图标：显示/隐藏宠物、退出
- 宠物窗口位置持久化，重启后还原

## 预留接口

- `renderer`：`render(status)`，当前 `TextRenderer` 显示文字，未来动画渲染层替换为贴图/骨骼动画实现，交互层代码不用改。三个状态对应的初始资源已放在 `public/pet/waiting.gif` / `open.gif` / `moving.gif`（取自 `chester_states_all/`）
- `backendClient`：`reportStatus()` / `fetchPetConfig()` 桩接口，当前本地 mock，未来后端服务层接入时只替换这个模块
