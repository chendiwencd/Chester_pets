# ChesterBot

ChesterBot 是一个将桌面宠物、个人知识库和智能工作区结合在一起的桌面助手。

它支持文档导入、素材整理、便签记录、截图沉淀和智能问答，并可通过 Agent 协助完成常见桌面操作。相比单纯的聊天工具，ChesterBot 更强调“收集、整理、理解、执行”一体化的使用体验。

## 什么是 ChesterBot

聊天、记录、截图或资料管理，日常工作往往发生在这些动作的连续切换之间。ChesterBot 希望把这些分散步骤收拢到同一个桌面入口中，让信息从“看到”到“保存”，再到“整理”和“提问”形成一条更顺畅的路径。

一个更贴近日常使用场景的个人工作区。你可以理解为一个始终在桌面侧边待命的助手，既能承接内容，也能帮助处理任务。

## 项目简介

ChesterBot 试图把日常使用中分散的信息入口集中起来。无论是文件、图片、文本、截图，还是临时想法和问题，都可以先进入同一个工作区，再围绕这些内容继续整理、提问和调用智能能力。

桌面宠物提供了一个更轻量的入口，而工作区则负责承载主要功能。这样既保留了日常使用时的陪伴感，也让资料管理和智能交互更自然地融入桌面工作流。

## 核心能力

### 文档与知识库

支持导入文件、图片和文本内容，并统一沉淀到素材区中。导入后的内容可以继续被查看、分类、引用和整理，逐步形成个人知识库。

### 智能问答

支持围绕已有资料进行提问、总结和延展回答。对话不再只是独立的一问一答，而是可以和你的资料内容建立关联。

### 便签整理

支持随时记录想法、结论和待整理内容。便签可以与素材联动，帮助你把零散信息逐步整理成更完整的记录。

### 截图沉淀

支持快速截取屏幕内容，并将截图进一步保存、识别或整理。这样临时看到的重要信息也能被及时留下，而不是停留在一次性的操作里。

### Agent 桌面操作

支持通过 Agent 协助完成常见桌面任务，例如打开应用、读取系统信息、执行浏览器相关操作，以及调用扩展能力处理更复杂的工作流。

## 适用场景

### 学习与阅读

阅读文档、资料或网页时，可以先把内容导入素材区，后续再围绕这些内容进行提问、总结和回看。

### 日常信息收集

平时遇到有价值的文件、图片、文本或截图时，可以快速沉淀到同一个工作区中，避免内容散落在不同位置。

### 想法记录与整理

当你有临时灵感、待办事项或阶段性总结时，可以直接记录在便签中，并与已有素材建立联系，方便后续继续整理。

### 桌面辅助操作

当你希望减少重复操作时，可以让 Agent 协助完成一部分桌面任务，把注意力更多放在内容处理本身。

## 快速开始

### 1. 安装应用

安装 ChesterBot 后启动应用，即可在桌面上看到宠物入口，并进入工作区开始使用。

如果你希望快速构建

```
npm install  
npm run tauri build   
```

如果希望替换为独立后端，需要创建.env 文件并写入 VITE_API_BASE_URL=

### 2. 导入内容

先将文件、图片、文本或截图加入素材区，作为后续整理和问答的基础内容。

### 3. 开始整理

你可以通过便签记录想法，也可以将已有素材重新分类、查看和关联，逐步形成自己的内容结构。

### 4. 使用聊天与 Agent

当你需要快速理解文件内容，或希望系统协助完成部分操作时，可以直接进入聊天区发起提问或任务。
